Git Graph 的 lane 幾何

Lane 預算 問題分析 maxLane = 5 為什麼是個問題,以及它不只是難看——截斷會讓 merge 彎折和 鍵盤導覽拿 x 座標當 lane 相等的代理。附各家 git 工具的處理策略, 包含一個有人實作、測過、然後拒絕的方案。 欄寬階梯 解法 · 可調參數 三段式:六條以內完全維持現狀,超過先收窄欄寬到 9px,再不夠才加寬 gutter。 附一根分支數滑桿走完整條策略,以及畫法參數的即時調整。 Lane 抖動測試台 驗證 分頁載入時,已經畫好的那幾列會不會換欄位。按「載入更多」自己驗, 含兩種歷史形狀、預先載入的筆數,以及「凍結已畫的決策」這條替代路線。
